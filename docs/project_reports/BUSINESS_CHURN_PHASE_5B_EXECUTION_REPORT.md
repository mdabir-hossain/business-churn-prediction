## What Failed

The test suite initially failed on:

```text
tests/test_features.py::test_feature_helpers_use_synthetic_data_only
AssertionError: assert [4, 3] == [5, 3]
```

The failure was in the synthetic test expectation for `ServiceCount`.

## Root Cause

The `add_service_count` helper counts service columns equal to `"Yes"`, matching the original notebook logic. In the first synthetic row, `InternetService` is `"Fiber optic"`, not `"Yes"`. Therefore, the correct count is 4, not 5.

This was a test expectation issue rather than a source-code issue. Changing the helper would have made it diverge from the existing notebook logic and could have blurred the meaning of `ServiceCount`.

## What Was Fixed

Updated `tests/test_features.py`:

```text
Expected ServiceCount changed from [5, 3] to [4, 3].
```

No source feature logic was changed for this fix.
